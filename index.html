Hướng dẫn cấu hình thương hiệu, Google Sheets, AI proxy & GitHub Pages

Đổi thương hiệu: mở index.html bằng trình soạn thảo UTF-8, tìm CONFIG đầu JavaScript. Thay BRAND, HOTLINE, ZALO, ADDRESS, MAP_URL, ADMIN_PASSWORD (mặc định admin123). Minh họa SVG nằm ngay trong file; thay bằng ảnh data URI nếu muốn giữ một file offline. Thay các số liệu, hồ sơ và phản hồi mẫu bằng nội dung đã xác minh.

GitHub Pages: 1. Tạo repository và tải index.html vào main. 2. Settings → Pages → Deploy from a branch → main / root → Save. 3. Mở URL Pages khi GitHub triển khai xong. Có thể mở đúp file HTML trực tiếp, không cần thư viện, font hoặc máy chủ.

Google Sheets: tạo bảng tính → Extensions → Apps Script → dán mã dưới, thay SHEET_ID → Deploy → New deployment → Web app (Execute as Me; chọn quyền truy cập phù hợp) → dán URL /exec vào cấu hình CRM. Chỉ bật sau khi khách đồng ý. Endpoint công khai cần chống spam và kiểm soát truy cập khi vận hành thật.

function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  const s = SpreadsheetApp.openById('SHEET_ID').getSheets()[0];
  const safe = v => /^[=+@\-\t\r]/.test(String(v || '')) ? "'" + v : String(v || '');
  const rows = s.getDataRange().getValues();
  if (rows.some(r => r[0] === d.id)) return ContentService.createTextOutput('duplicate');
  s.appendRow([d.id,d.createdAt,d.name,d.phone,d.email,d.service,d.appointment,d.source,d.status,d.note].map(safe));
  return ContentService.createTextOutput('ok');
}

Webhook chỉ nhận yêu cầu mới, không đồng bộ hai chiều. Mỗi thiết bị có CRM cục bộ riêng. Gửi no-cors không đọc được xác nhận; trạng thái chỉ là “Đã gửi, chưa xác minh”. Sửa trạng thái hoặc xóa trên CRM không cập nhật Sheets. Mã mẫu chống trùng ID; cập nhật lead đã gửi không ghi đè dòng cũ.

AI mở rộng: cấu hình URL HTTPS của proxy do bạn quản lý. Proxy nhận POST JSON {message, context, instructions}, trả JSON {reply: "..."}. Giữ khóa OpenAI/Gemini trên máy chủ, bật xác thực, giới hạn tần suất và CORS đúng origin. file:// có origin null; dùng chế độ nội bộ khi mở file. Lỗi hoặc quá 12 giây tự trở về kịch bản. Tin chứa tên/SĐT/email được nhận diện sẽ xử lý cục bộ, không gửi proxy; nhận diện tự động không bảo đảm loại hết mọi dữ liệu nhạy cảm.

Quyền riêng tư: khóa CRM phía client chỉ khóa giao diện, có thể bị vượt qua bằng xem mã nguồn. Không dùng làm bảo mật hồ sơ thật. Khi triển khai thực tế cần backend có xác thực, phân quyền, chính sách lưu giữ và bảo vệ dữ liệu. Xuất CSV định kỳ vì localStorage có thể bị trình duyệt xóa. Xóa bản ghi mẫu không tự tạo lại sau F5.
